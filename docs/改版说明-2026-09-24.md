# 邻传 0.3.0 改版说明

日期：2026-09-24。起因：实际使用 0.2 后反馈界面不好看，且“配对太麻烦”“多文件要逐个确认”“不能发文件夹 / 文字”。主要使用场景为 Mac ↔ Windows。

## 功能

| 问题（0.2） | 0.3 |
| --- | --- |
| 两台电脑要手动复制同一个 64 位连接密钥 | 每台电脑自动生成设备密钥，打开即可发现对方；首次由接收方确认，可勾选“信任此设备”以后自动接收 |
| 一次发 N 个文件要确认 N 次 | 一个连接传一整批，只确认一次；确认框列出全部内容、文件数和总大小 |
| 不能发文件夹，需先压缩 | 直接发送文件夹，保留目录结构（含空文件夹） |
| 不能发文字 | 发送文字或链接，对方弹窗显示，可复制、打开链接 |
| 需点“刷新”，查找 3 秒 | 后台持续发现，设备自动出现 / 消失；退出或关闭接收时立即通知对方 |
| 设置需点“保存设置”，传输中不能保存 | 设置即时生效 |
| 失败只能重新选择文件 | 传输记录中可“重试”；收到的文件可“打开”“显示” |
| ⌘Q 绕过退出确认 | 关闭 winit 默认菜单，⌘Q 由界面处理，有传输时先询问 |

其他：默认设备名取电脑名称（Mac 为“电脑名称”，Windows 为计算机名）；已信任设备记录上次地址，广播被阻断时直接探测；手动输入 IP 的设备响应后自动切换为正常设备；接收方最多 8 个并发连接，握手和请求须在 10 秒内到达。

## 界面

- 主页：附近的设备（圆形头像网格，Mac 显示笔记本图标、Windows 显示显示器图标，已信任设备标注“已信任”，最后一格“输入 IP”）→ 要发送的内容（文件 / 文字切换；文件列表显示类型、大小，文件夹后台统计文件数）→ 底部“发送给 …”按钮。进行中的传输以进度条显示在按钮上方，点击进入传输记录。
- 传输记录：进行中 / 已完成两组，显示方向、对方、文件数、大小、时间、进度、速度、剩余时间、当前文件；按状态提供取消、打开、显示、复制、重试。
- 设置：本机（名称、IP 地址）、接收（允许接收、只接收已信任设备、保存位置）、已信任的设备（含指纹，可移除）、通用（关闭窗口后保留在菜单栏 / 托盘）、版本与本机指纹。
- 对话框：收到文件（头像、内容列表、信任选项、指纹、倒计时）、收到文字、退出确认、输入 IP。
- 视觉：统一的语义配色（浅色 / 深色）、12 px 圆角卡片、分组列表、分段控件、开关与复选框、提示条（带“打开文件夹”“查看”等操作）、全窗口拖放提示。窗口默认 460×660，最小 400×540，放宽后内容居中不超过 560。

## 协议与安全

- 握手：Noise_XX_25519_ChaChaPoly_SHA256（snow 0.10，未启用 ring），双方证明设备密钥，每个连接新会话密钥；握手前双方交换 8 字节版本标记，与旧版或其他程序连接时立即报告“版本不同”。
- 数据帧：2 字节长度 + Noise 消息，文件数据每帧 64000 字节，每个文件结束附 SHA-256。
- 信任模型为首次信任：未信任设备必须经确认；确认框显示对方指纹（公钥的 SHA-256 前 6 字节），可与对方设置页核对。按列表中的设备发送时，会核对握手得到的身份与发现时公布的一致。
- 接收方写盘前校验全部条目；只写入接收目录内新建的顶层文件夹或新文件；临时文件在失败、取消时删除。
- 未解决：首次连接时同一局域网内的主动中间人攻击（与 LocalSend 等同类工具相同）；可通过核对指纹发现。

## 兼容性

- 0.3 与 0.2 不能互传：双方不会出现在对方的设备列表中；手动输入旧版电脑的 IP 发送时，会提示对方版本不同。
- 设置文件位置不变。保留名称、保存位置、是否接收、关闭窗口行为；首次启动生成设备密钥并删除旧的连接密钥；旧的“自动接收”不再使用。

## 验证

环境：Linux x86_64 云端容器，Rust 1.95。

- 自动测试 20 项全部通过；`cargo clippy --all-targets`（含 `demo` 功能）无警告；`rustfmt` 已格式化。
- 界面：虚拟显示器中以 2 倍缩放渲染真实窗口并截图检查，覆盖浅色 / 深色、全部页面与对话框、400×540 最小窗口和加宽窗口。
- 端到端：两个 Linux 网络命名空间通过虚拟网线组成局域网，各运行一个应用实例。通过界面完成：双方自动发现 → A 发送 1 个 30 MB 文件、1 个文本文件和 1 个文件夹（含子文件夹、空文件夹、.DS_Store）→ B 弹出一个确认框（4 个文件，.DS_Store 已跳过）→ 勾选信任并接收 → 文件逐字节一致、目录结构完整、B 的设置中记录信任 → A 发送文字，B 显示并识别链接 → A 重启后再次发送，B 未询问直接保存，重名文件编号 → A 按 Ctrl+Q 退出，B 的设备列表立即清空。
- 未覆盖：Mac、Windows 实机运行；Mac 与 Windows 之间的真实 Wi-Fi 互传；Windows 专用代码（窗口唤起、资源管理器中显示）只在 Mac 上交叉编译时检查。
