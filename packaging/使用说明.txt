邻传 LAN Transfer 0.3.0
Mac 与 Windows 局域网文件互传

一、打开程序
Mac：双击“邻传.app”，无需安装。首次运行如系统询问是否允许查找本地网络上的设备，请选择允许。
Windows：解压整个文件夹，双击 LanTransfer.exe，无需安装。请让 libunwind.dll 留在 exe 同一目录。Windows 防火墙询问时，允许“专用网络”。
两台电脑需要连接同一个 Wi-Fi 或局域网。

二、发送
1. 两台电脑都打开邻传，“附近的设备”里会自动出现对方，不需要任何设置。
2. 把文件或文件夹拖进窗口，或点击“选择文件”“选择文件夹”；要发文字或链接，切换到“文字”。
3. 选中对方，点击底部的“发送给 …”。
找不到对方时，点击“输入 IP”，填写对方“设置”中显示的 IP 地址。

三、接收
收到文件时会弹出确认框，列出这一批的全部文件和总大小，点击一次“接收”即可。约两分钟内未确认会自动拒绝。
勾选“信任此设备，以后自动接收”后，这台设备以后发来的文件和文字会直接到达，不再询问。信任只能在这个确认框里完成（此时对方身份已经过加密握手核实）。已信任的设备可在“设置”中移除，也可以在设备图标上点右键取消信任。
收到的文字同样先确认（已信任设备发来的直接弹出），可一键复制，或打开其中的链接。
确认框会列出这一批的全部内容，接收文件夹所在磁盘放不下时会用红字提醒；已信任设备发来放不下的内容会直接拒绝并说明原因。
发送失败时，记录里会显示对方给出的原因（例如对方磁盘空间不足）。
文件默认保存在“下载”中的“邻传接收”，可在设置中更改。重名时自动加编号，例如“报告 (2).pdf”，不会覆盖已有文件。

四、传输记录
点击右上角的双向箭头打开传输记录，可查看进度、速度和剩余时间，取消传输，打开收到的文件，或重新发送失败的内容。记录只保留本次运行期间的内容。

五、后台运行与退出
关闭窗口后邻传留在菜单栏／系统托盘，仍可接收文件；第一次收起时会有一条系统通知说明。窗口收起期间收到文件、接收或发送失败都会通过系统通知提醒。Mac 上点击菜单栏图标选择“打开邻传”恢复窗口；Windows 上单击托盘图标即可打开窗口，右键显示菜单。选择“退出邻传”完全退出；Mac 上也可以按 ⌘Q。仍有传输时会先询问。
程序不会自动设置开机启动。

六、设置
设备名称、IP 地址、是否允许接收、只接收已信任设备、保存位置、已信任的设备、关闭窗口后的行为。所有更改立即生效，无需保存。
“IP 地址”优先显示 Wi-Fi／以太网的地址，Docker、VPN、虚拟机等虚拟网卡的地址排在后面。

七、安全
每次连接都用各自的设备密钥做加密握手（Noise 协议：X25519、ChaCha20-Poly1305、SHA-256），传输全程加密，每个文件都做 SHA-256 完整性校验。文件只在两台电脑之间直接传输，不经过云端。
不在信任列表中的设备必须经你确认才能发送文件或文字；开启“只接收已信任设备”后，其他设备的请求会被直接拒绝。
设备名称只是提示。需要确认对方身份时，可把确认框里的“指纹”与对方“设置”底部的“本机指纹”核对，一致即为同一台电脑。

八、已知边界
- 0.3 与旧版 0.2 不能互传，两台电脑都需要更新。旧版的“连接密钥”和“自动接收”设置不再使用；首次收到对方文件时勾选“信任此设备”即可。
- 仅支持 IPv4 局域网。访客 Wi-Fi、路由器的 AP 隔离或 VPN 可能阻断发现或传输，这时可尝试“输入 IP”。
- 不支持断点续传和跨互联网传输。
- 单个文件不超过 100 GB，一次最多 10000 个文件和文件夹。
- 文件名需兼容 Windows（不含 \ / : * ? " < > | 等字符）。直接选择的文件名不兼容时会提示改名；文件夹里不兼容的文件、快捷方式（符号链接）会跳过并在记录中说明；.DS_Store、Thumbs.db 等系统文件不会发送。
- 发送期间不要修改源文件；接收方磁盘空间不足会导致失败，已收到的部分会保留。
- 没有进行 Apple 公证或 Windows 发布者签名，系统可能提示未知开发者。
- Mac 需要 macOS 11 或更新；Windows 面向 Windows 10/11 64 位，需要支持 OpenGL 3.3 的显卡驱动。

连接端口：TCP/UDP 45873；本机单实例控制端口：127.0.0.1:45874。
