# 0.3 测试

运行 `cargo test --release -- --test-threads=1`。默认执行 23 项自动测试，使用回环地址和独立临时目录，设置写入临时目录（`LAN_TRANSFER_CONFIG_DIR`），不安装应用、不读写真实用户设置。

`support/network_cases.rs`（19 项）：

- 文件、空文件、9 MB 文件和含空子文件夹的文件夹在一个批次中完整到达，`.DS_Store` 不发送；
- 未信任设备整批只询问一次，勾选信任后下一批直接接收；拒绝后整批停止、不写盘；
- 已有同名文件和文件夹不被覆盖，编号保存；
- 文字送达，空文字不发送；未读文字积压时新的文字带原因拒收；
- 关闭接收、只接收已信任设备时带原因拒绝；
- 等待确认时发送方取消，接收方撤回确认框；接收中接收方取消，发送方立即停止且不留临时文件；
- 接收方失败时发送方收到失败回执与原因，而不是单纯断开；
- 同一地址最多占 3 个接收连接；
- 设备身份与列表不一致时停止发送；端口上是其他程序或旧版时提示版本不同；
- 路径穿越、绝对路径、Windows 盘符与保留名、反斜杠、方向控制字符、大小写重复、文件与文件夹冲突、超大文件、空请求在写盘前被拒绝；
- 截断、校验错误、超长、取消、乱码数据帧都不留下临时文件；
- 扫描文件夹时跳过符号链接（含单独选中的链接）、系统文件和 Windows 不支持的文件名，同名的顶层项目自动编号；
- 编号、摘要、文件名规则；0.2 旧设置迁移；
- 设备发现：hello / reply 互相发现，bye 立即移除，关闭接收的设备不显示。

`src/ui/`（4 项）：浅色与深色、三种窗口尺寸下渲染全部页面、文件与文字两种模式、各对话框；半粗标题字体子集覆盖界面中的全部汉字；链接识别；文本截断。

端到端检查不在自动测试中：在两个 Linux 网络命名空间中各运行一个应用实例（虚拟显示器、`--features demo` 的 `LAN_TRANSFER_PICK` 预选文件），通过界面完成发现、发送、确认、信任、发文字和退出，结果记录在 `docs/改版说明-2026-09-24.md`。
